# Consulta UNIPEGA · Maper

App para estudar os produtos Unipega e descobrir qual indicar ao cliente. Especificação em `docs/SPEC.md`.

## Rodar

```bash
cp .env.example .env.local   # preencha a URL e a chave pública do Supabase
npm install
npm run dev
```

Não há cadastro público: crie os usuários no painel do Supabase (Authentication → Users).
